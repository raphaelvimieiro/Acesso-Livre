As telas do sistema apresentam uma estrutura padronizada, conforme ilustrado na Figura 2. Nessa organização, identificam-se três blocos principais, os quais serão descritos a seguir.São eles:

### Tela - Home page

A tela de Home page apresenta na Figura 3, é uma página na qual o usuário não está cadastrado. Nesta página mostra-se, no **cabeçalho**, a logo **AcessoLivre**, links de navegação (Início, Sobre, Notícias, Denúncia), uma barra de busca de locais/bairros e um botão de **Entrar/Criar conta**. 
No **conteúdo**, podemos observar banners, algumas avaliações e comentários realizados por usuários cadastrados.
Já no **rodapé**, temos informações sobre direitos autorais.

### Tela - Entrar/Criar conta
A tela de Entrar é destinada exclusivamente aos usuários já cadastrados na plataforma **AcessoLivre**. Em seu conteúdo, são apresentados os campos de **E-mail** e **Senha** para autenticação, além de um botão de marcação para que o usuário possa optar por
manter suas credenciais salvas no dispositivo. Ademais, a página disponibiliza um botão que redireciona o usuário para a tela de criação de conta, caso ainda não possua um cadastro na plataforma.

### Tela - Avaliação 

A tela de Avaliação é acessível exclusivamente aos usuários cadastrados na plataforma**AcessoLivre**. Nesta página, o usuário pode relatar problemas de acessibilidadeselecionando uma das seguintes categorias: **Acessibilidade**, **Obra/Bloqueio**, **Informação Errada** e **Outros**.

Ademais, a tela disponibiliza os seguintes campos para preenchimento:
- **Nota:** avaliação em formato de estrelas, variando de 0 (Muito Ruim) a 5 (Ótimo);
- **Local:** campo destinado à identificação do local avaliado;
- **Descrição:** campo para que o usuário descreva detalhadamente sua experiência como local visitado.

Por fim, a página apresenta uma caixa de seleção para que o usuário opte por realizar o relato de forma **anônima**, e um botão de **Registrar** para concluir o envio daavaliação.
