# Template padrão da aplicação

A estrutura base do site foi desenvolvida utilizando **HTML e CSS** para a criação da interface e estilização das páginas, enquanto o **JavaScript** foi aplicado na implementação de funcionalidades interativas, como o menu responsivo. Além disso, o framework **Bootstrap** foi utilizado para auxiliar na responsividade e organização dos componentes visuais da aplicação web.

Cada página mantém uma organização visual padronizada, composta por menu de navegação, header e footer, garantindo consistência visual e melhor experiência de navegação para o usuário.

---

## Controle de acesso da aplicação

Algumas funcionalidades da aplicação estão restritas apenas a usuários autenticados. Usuários que não estiverem logados, não obtêm acesso à área de pesquisa e à página de avaliação. Desse modo, garantimos maior segurança e confiabilidade das informações dispostas em nosso site.
